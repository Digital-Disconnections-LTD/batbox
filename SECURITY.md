# Reporting security issues

Please report vulnerabilities privately through GitHub’s **Report a vulnerability**
option when it is available. Otherwise, use a private contact method listed on a
maintainer’s GitHub profile. Do not disclose a working exploit or credentials in
a public issue while the report is being assessed.

Include the affected version or commit, platform, reproduction steps, impact, and
any suggested fix. Maintainers will coordinate a fix and disclosure with you.
There is no guaranteed response time or security-support window during preview.

Batbox can run shell commands and edit local files. Review approvals and connect
only the model endpoints, MCP servers, and helpers you intend to trust. Poetry,
conversation context, and Gadget results may be sent to those configured services.
