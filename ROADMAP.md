# The next Flight 🌙

Batbox is a community project moving toward its first production release. These
are outcomes to work toward, not promised dates. Contributions and practical
feedback will help decide the order.

## First release

- Complete interactive acceptance on Linux, macOS, and Windows: keyboard input,
  resize, scrolling, Unicode, clipboard, clean exit, and recovery.
- Exercise Messages streaming, cancellation, retries, compaction, and interrupted
  Flights against multiple compatible backends.
- Validate portable runtime packages on clean machines; finish macOS library
  bundling, signing, and notarization, plus Windows interactive acceptance.
- Review dependency notices for every distributed runtime and optional media loader.
- Test MCP reconnection, credential persistence, and browser authentication on
  each desktop platform.
- Make the first-Flight experience clear enough to follow without outside help.

## Grow the Roost

- Better accessibility and terminal color choices.
- Small contributor Missions with reproducible examples.
- More backend and language-server compatibility reports.
- Clearer coordination of multiple Bats, including entering their conversations,
  sending follow-ups, and returning to the leader.
- A Flight manager for multiple independent sessions working on different
  projects or Missions in one window.
- More interactive UI testing and fixes alongside the headless checks.
- Better Flight recovery and Mission visibility.
- Community artwork and a recognizable, joyful Batbox identity.
