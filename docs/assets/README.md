# Batbox artwork

`batbox-halloween.png` is the GitHub front-page banner. It was generated with the
built-in image generation tool using the maintainer’s Halloween garden photograph
as a visual reference: a purple bat, a cheerful white ghost, and orange lights.

The art direction is recorded in `banner-poetry.txt`. Keep the banner’s alt text
useful, its wordmark legible, and the community tone warm when proposing variants.
